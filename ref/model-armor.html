Model Armor, Canonical Normalization & Cloud SDP Surrogate Tokenization

Defense-in-depth screening for inbound user prompts and outbound/inbound MCP database tool payloads.

1. Three-Layer Content Protection: Normalize, Screen (Fail-Closed), and De-identify

Content screening is a probabilistic mitigation that backs up our deterministic boundaries (tools.yaml, FORCE RLS, and HITL gates). To prevent attackers from bypassing screening via Unicode tag characters or Base64 encoding inside database text columns, we combine gateway-level Model Armor with canonical normalization and Cloud Sensitive Data Protection (SDP).
