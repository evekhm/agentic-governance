Reference · OWASP Mapping

Threats T1–T8 Mapped to the OWASP Top 10 (Agentic 2026 · LLM 2025 · Classical)

Each threat in Figure 2 is a well-documented attack class. Mapping them to the OWASP lists lets the rest of the series refer to T1…T8 and cite the standard identifiers rather than re-describing each attack.

Two OWASP lists are relevant. The OWASP Top 10 for LLM Applications (2025) describes failure modes of any application that embeds a language model: prompt injection, sensitive information disclosure, improper output handling, and so on. The OWASP Top 10 for Agentic Applications (2026) extends this to systems in which the model is given tools, memory, and autonomy; its entries describe what happens when a fooled model can act. Because our agent reads and writes a database, several of the threats are also classical web and API weaknesses in new clothing—broken object-level authorization and SQL injection in particular—so the classical identifiers are listed as well.

Two observations follow from the table. First, several threats share an OWASP category (ASI03 appears four times) because the root cause—one privileged identity standing in for every user—shows up at more than one point in the architecture. Second, no threat is closed by instructing the model. Every row needs a control that sits outside the model: in the identity layer, in the tool server, in the database engine, or in the network. The next parts add those controls one component at a time.
